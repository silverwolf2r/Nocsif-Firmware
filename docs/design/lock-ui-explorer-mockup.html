Peek v2 — this pass

Centre: weather (temp + glyph) over the big time + italic date. Top-right: battery %, and an accent-tinted Bluetooth glyph when the phone is linked (present-only — never blue). No top-left alert count; a Focus/DND mark can sit there.

Activity chip: the top live task under the time — swipe it to cycle when several run, tap to open. Dials: drag a side up/down to rotate; they clamp at the ends and peek the next planet. Long-press a planet to change its launch target.

Control Center: pull the top handle down (or swipe from the top edge) → DND · Alerts · Flashlight · brightness · Wi-Fi / BLE / Airplane · a task progress bar · media transport. Swipe up from the bottom to close. This is the walkable prototype for the full-app mockup's peek + shade.

Switch palette / font / wallpaper / peek state above. Drag a side to rotate a dial; tap a planet to launch, long-press to re-target it. Pull the top handle down for the Control Center (swipe up from the bottom to close). Swipe the activity chip to cycle tasks. Swipe up / tap the handle for the menu; drill into WiFi › Scan for the decrypt-in. Hold still ~3s → it sleeps (double-tap to wake).
