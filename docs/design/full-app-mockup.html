Done-state · v2

The whole watch in the v2 IA: Home is a three-circle hub — Life (everyday), Cyber (radios + full tooling), System (settings) — long-press a circle to change its sun / moon / planet motif. The watchface puts weather over the time, battery + an accent Bluetooth glyph top-right, a swipe-to-cycle activity chip, and two edge carousels of planets you drag to spin (long-press to re-target any to a launch id — including a whole hub). Pull down from the top for the Control Center. Fully walkable; hero screens include Scan, Signal Hunt, Diagnostics, Power & Battery, and the companion panel below.

Accent only touches interactive marks, the // captions, tags, the cursor, one star, the sweep. Grit is a dither grain, wake/nav glitch, a blinking cursor, terminal chrome — no scanlines.

Physical buttons (right edge, both real on the Ultra): PWR — screen on/off, back-to-watchface from a menu, long-press power menu (AXP2101, fully programmable). FN — assignable action button (wired here to Signal Hunt); it's GPIO0, so holding it at boot enters USB download mode. A recessed RST also exists but is hardware-only (not usable in software).

Accidental-touch / palm rejection (worn on a wrist — palming, cuffs, rain, pocket): waking needs a deliberate gesture — PWR, double-tap, or wrist-raise (IMU) — never any stray touch; while asleep the touchscreen is ignored except that wake gesture. A brief post-wake input-lock (~450 ms) stops the wake contact bleeding into a planet/action, and idle no longer re-arms on a stray hover — only an accepted tap does. Palm/multi-contact rejection uses the CST9217's two-point report + a dwell/debounce at ~33 Hz and its cover-screen status flag (a coarse large-object hint) — the panel decodes no contact-area, so there's no touch-major test; edge rejection must carve out the edge planet hit-zones. Movie mode / pocket hard-lock the touchscreen (PWR still works). Full model in PLAN §4.5.

This is the growth canvas — folded so far: the v2 hub + edge carousels + Control Center, assignable planets, gestures, depth / shooting-stars, companion control, Ghost-ESP Cyber parity, phone-first timekeeping. Deity palettes (helios · eris · priapus · eros · hades) use the real linux-antiquity accent hexes from their quickshell config (MIT, credit diinki); grounds stay near-black for AMOLED. Long-press a planet (or System › Peek & Shortcuts) to re-target which app it launches.

Companion · L4 / M5 + M7

Both transports, co-equal. The web UI is app-free — the watch serves nocsif.local on its own SoftAP (or a joined network); any phone browser controls it and fills watch fields, so on-watch typing stays rare. The BLE companion app is always-on and low-power, and carries notification mirroring (ANCS).

Full scope — launch & run saved macros, type into any field, browse / drop / pull files on /sd (all co-equal over both transports), and live-view + drive the watch (rides the WiFi transport — framebuffer streaming is impractical over BLE).

Light guardrails — PIN pair, off by default, a subtle indicator while linked, session log optional. Credential-class actions keep their own on-watch armed indicator. Reuses M5 (web UI) + M7 (BLE).

On-watch typing (v1 fallback) — offline QWERTY for short strings + voice dictation (mic → cloud STT over WiFi). Scribble is experimental; predictive swipe isn't planned.

Switch palette / font / wallpaper above, or open System › Watch Face. On the peek: drag a side to spin its carousel, tap a planet to launch, long-press to re-target it; swipe up for the Life / Cyber / System hub, pull down from the top edge for the Control Center (swipe up from the bottom to close). Long-press a hub circle to change its motif. Try Cyber › Wi-Fi (extended tooling), Signal Hunt, System › Power & Battery, and Diagnostics. Side buttons: PWR (screen off / back · long-press power menu) and FN on the right edge. The companion panel below still drives the watch — tap its tabs (control / type / files / live).
