Rotation sweep, gyro-only (no magnetometer) — bearing is relative to your start facing, shown clock-style. Multipath smears it indoors.

Grounded / bounded

What feeds it

BLE & WiFi RSSI (2.4 GHz, native radio) — strongest, high update rate on anything that beacons. SX1262 915 MHz — partial: RSSI on one pre-tuned narrowband channel, cooperating emitter only. NFC — n/a (cm range).

Why bearing is "relative"

The BHI260AP is accel+gyro only — no magnetometer on this board (LilyGo's compass code is gated to a chip the Ultra doesn't have). Heading is gyro-integrated yaw: fine over one ~10 s sweep, drifts over minutes. So the readout is clock-relative, never a compass bearing.

Physics, honestly

One omni antenna gives strength, not direction — this is gradient hunting ("warmer / colder"), and a body-shadow lobe from your own 2.4 GHz absorption. Unknown Tx power → trust the trend, not absolute distance.
